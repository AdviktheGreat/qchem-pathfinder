# Interdisciplinary bridge scientific review matrix

This matrix records the editorial review of every released bridge. “Evidence basis” names the concrete scientific overlap expressed by the bridge; it is not a claim that two fields are interchangeable. “Boundary recorded” confirms that the student-facing distinction keeps the source and destination lenses separate. Review status covers scientific plausibility, beginner-facing terminology, a usable shared question, and score-free language.

## Review rule

A bridge remains release-ready only when its row is present, its canonical IDs and labels pass registry validation, its shared question and searches pass content validation, and its boundary copy makes the two research lenses meaningfully different. Any scientific wording change should update the corresponding row and be reviewed with the link data in the same commit.
